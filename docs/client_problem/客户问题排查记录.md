## 2026-08-28 · 5726 TX 与 5706 RX 无线连接适配

### 一、背景

- 573x SDK（发送端 TX，工程目录 `5726_TX`）与 5706 SDK（接收端 RX，工程目录 `5706_RX`）组成 2.4G 无线麦克风系统。
- 需求：让发送端与接收端通过私有 2.4G 无线协议正常建立连接并传输音频。

### 二、问题根因

两端当前激活配置的无线链路参数不一致，导致协议版本不匹配、无法握手：

| 参数 | 5726 TX | 5706 RX（修改前） | 结论 |
|------|---------|------------------|------|
| `WIRELESS_CON_VERS` | 6（V7 领夹麦） | 2（V3 K歌） | **不一致，协议版本不同无法连接** |
| `WIRELESS_MIC_TX_INTERVAL` | 6 | 2 | **不一致，帧周期不同** |
| `WIRELESS_CON_CODEC_SEL` | WS_CODEC_LC3S | WS_CODEC_LC3S | 一致 |
| `WIRELESS_CON_FREQ_BAND` | 0 | 0 | 一致 |
| `WIRELESS_CON_LINK_NB` | 2 | 2 | 一致 |
| `WIRELESS_CON_CON_ID_SEL` | 0x00 | 0x00 | 一致 |
| `WIRELESS_CON_RSSI_THR` | 70 | 70 | 一致 |
| 采样率/样点/声道/帧长/重传 | 48K / 120 / 单声道 / 25 / 3 | 48K / 120 / 单声道 / 25 / 3 | 一致 |

`WIRELESS_CON_VERS` 是传输机制版本（2=V3 一般用于 K 歌话筒，6=V7 一般用于领夹麦，8=V9 用于一拖多），两端必须一致才能完成握手。

### 三、修改内容

仅修改接收端一个文件（发送端已是 V7，无需改动）：

文件：`5706_RX/projects/microphone/config_ab5706a_rx.h`

1. `WIRELESS_CON_VERS`：`2` → `6`（V3 → V7）
2. `WIRELESS_MIC_TX_INTERVAL`：`2` → `6`（帧周期对齐）

后补一处（串口调试用）：

3. `UART0_PRINTF_SEL`：`PRINTF_VUSB` → `PRINTF_PB3`（打印口切到物理串口 PB3，方便烧录后串口排查；PB3 与 USBDP 复用，改后 RX 端 USB device 被关闭，但 RX 端本就没开 USB 设备功能，无实际影响）

### 四、测试原理

无线链路需要两端以下参数一致才能建立连接：

- 传输机制版本 `WIRELESS_CON_VERS`
- 帧周期 `WIRELESS_MIC_TX_INTERVAL`
- 编解码 `WIRELESS_CON_CODEC_SEL`（LC3S）
- 工作频段 `WIRELESS_CON_FREQ_BAND`
- 连接 id `WIRELESS_CON_CON_ID_SEL`
- 采样率 / 每帧样点数 / 声道 / 压缩帧长 / 重传次数

串口日志验证方式：

- TX（发送端）日志出现 `WL_CON`、`con_sta = 1`、`con_complete`、`state = 4` 表示已连接；`TX: pdu=...` 表示正在发送音频帧；`rx_cntl(...)` 表示收到 RX 回传的控制帧（双向链路正常）。
- RX（接收端）日志在 adapter 侧应有 scan → 连接成功的对应输出。

### 五、测试结果

- 两端均重新编译通过（TX 170 个源文件，RX 120 个源文件），无错误。
- 烧录后两端正常连接，音频传输正常，双向通信正常。

TX 关键日志摘录（已连接证据）：

```text
WL_CON, 0
emit, con_sta(0): 1
emit, con_complete
emit, state: 4
wl_audio_start_cb, 6, 0, 0
TX: pdu=(75B, 722), intv=(7500, 722), retry=(3, 4)
rx_cntl(1): 01 00 ...
```

其中 `wl_audio_start_cb, 6, ...` 的 `6` 即 V7 协议（`WIRELESS_CON_VERS=6`），证明版本对齐生效；`intv=(7500, ...)` 即 `TX_INTERVAL 6 × 1.25ms = 7.5ms`。

### 六、编译与烧录

编译（脱离 Code::Blocks，需 RV32 工具链，脚本会自动探测）：

```powershell

powershell -ExecutionPolicy Bypass -NoProfile -File "5706_RX/projects/microphone/build.ps1" -Rebuild
# 发送端
powershell -ExecutionPolicy Bypass -NoProfile -File "5726_TX/projects/microphone/build.ps1" -Rebuild
```

产物：各工程 `projects/microphone/Output/bin/app.bin`、`app.dcf`。

烧录配置档：

- 5726（发送端）：`wireless_mic_emit`
- 5706（接收端）：`wireless_adapter`
